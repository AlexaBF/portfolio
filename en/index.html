Foodbank webpage

Speed up the process of recollection of a food bank.

Given that the food bank of Mexico (BAMX) in Morelos provides a service for beneficiaries, the employees at BAMX need to have control of the operations in BAMX, therefore we created a website with three types of users:

- Admin: Manage users and visualize BAMX reports.

- Cashier: Register the attendance of the beneficiaries.

- Social Worker: Manage the of attendance beneficiaries, manage beneficiaries, manage petitions from beneficiary communities, and visualize reports.

My role: I assisted with the creation of API endpoints, performing comprehensive API testing using Jest, and verifying the optimal performance of the web page through the utilization of a web driver.

JavaScript Selenium Jest Figma git Github

IoT for Plants

Monitor a plants humidity, temperature, and sun exposure through a web page.

To keep track of a plant's humidity, temperature, and sun exposure, we use a nodemcu with three sensors in order to measure those charecteristics of the plant. Through an arduino script the data collected was send to a webpage where you can monitor your plant.

My Role: Read the values registered in the sensors attached to the plant and send them to the web page for better visualization.

Arduino Esp32 Freeboard Tinkercad

Soft Skills Evaluator Game

Develop a video game that evaluates three soft skills (working under pressure, problem-solving, and ethics, trust & values) of an eligible candidate for a job in MINSAIT.

To further evaluate a candidate, MINSAIT applies a soft skill test to their candidates, sometimes the candidate is familiar with the questions being asked so they choose the expected answer. One of the possible solutions is to evaluate the candidate's soft skills through a video game where they don't have explicit questions but rather actions to evaluate their soft skills.

My Role: I assisted with the game design, programming of game functions, and score design for the three soft skills.

C# Unity
