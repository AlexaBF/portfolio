Sitio web BAMX

Agilizar el proceso de recolección de un banco de alimentos.

Dado que el Banco de Alimentos de México (BAMX) en Morelos presta servicios a sus beneficiarios, el personal de BAMX requiere controlar las operaciones de la organización; por ello, desarrollamos un sitio web con tres tipos de usuarios:

- Administrador: Gestiona usuarios y visualiza informes de BAMX.

- Cajero: Registra la asistencia de los beneficiarios.

- Trabajador social: Gestiona la asistencia y los datos de los beneficiarios, administra las solicitudes de las comunidades beneficiarias y visualiza informes.

Mi rol: Colaboré en la creación de endpoints de la API, realicé pruebas integrales de la API utilizando Jest y verifiqué el rendimiento óptimo del sitio web mediante el uso de un controlador web (web driver).

JavaScript Selenium Jest Figma git Github

IoT para plantas

Monitorea la humedad, la temperatura y la exposición solar de una planta a través de una página web.

Para realizar un seguimiento de la humedad, la temperatura y la exposición solar de una planta, utilizamos una placa NodeMCU con tres sensores para medir dichas características. Mediante un script de Arduino, los datos recopilados se enviaban a una página web donde es posible monitorear la planta.

Mi rol: Leer los valores registrados por los sensores conectados a la planta y enviarlos a la página web para una mejor visualización.

Arduino Esp32 Freeboard Tinkercad

Juego de evaluación de habilidades blandas

Desarrollo de un videojuego para evaluar tres habilidades blandas (trabajo bajo presión, resolución de problemas y ética, confianza y valores) de un candidato apto para un puesto en MINSAIT.

Para evaluar más a fondo a los candidatos, MINSAIT aplica pruebas de habilidades blandas; sin embargo, a veces el candidato ya conoce las preguntas y elige la respuesta esperada. Una posible solución consiste en evaluar dichas habilidades mediante un videojuego que no plantee preguntas explícitas, sino que utilice acciones para evaluarlas.

Mi rol: Colaboré en el diseño del juego, la programación de sus funciones y el diseño del sistema de puntuación para las tres habilidades blandas.

C# Unity
